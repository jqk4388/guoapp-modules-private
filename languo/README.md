# 蓝果短剧

小果影视（guoapp）站源模块，接口第 1 版。

- 内容：男同短剧、AI 短剧、蓝果原创、男同 GV
- 功能：分类浏览、分页、搜索、详情、播放、**按地址发布页自动切换最新域名**
- 限制级：是

## 安装

在应用「模块」页从 zip 安装，或把本目录放到数据目录的 `modules/languo/`。

## 线路

- 进入站源时先读地址发布页（`languoai.pages.dev`、`languotv.com`、`languo5.com`、`languo.ai/go-home/`），把上面的当前备用地址逐个探测，第一个能返回剧目列表的作为线路。
- 选中的线路连同探测时间写进模块状态；6 小时内直接复用，不重复探测。
- 任何一次请求失败都会立刻丢弃当前线路，重读发布页再探测一次，然后继续原来的请求。
- 发布页上出现清单没声明的新域名族时，需要在 `manifest.json` 的 `hosts` 里补一项；否则模块只能退回发布页里的中文永久入口。

## 说明

- 分类从首页的分类条读取，站点改版后自动跟着变；「短剧热播」「蓝果原创」「男同GV」固定。
- 标签页只有一页，翻页返回空列表。
- 播放地址取自详情页的 `videoInitialData`，每集播放前重新取一次，链接过期不影响使用。

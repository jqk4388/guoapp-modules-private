# TheGay

小果影视（guoapp）站源模块，接口第 1 版。

- 内容：欧美男同影片，站点约 108 万条
- 功能：分类浏览（230 个分类 + 最高评分 / 最热 / 最长）、分页、关键词搜索、详情、直接取 mp4
- 限制级：是

## 安装

在应用「模块」页从 zip 安装，或把本目录放到数据目录的 `modules/thegay/`。

## 说明

- 目录、搜索、详情都走站点的 JSON 接口：`/api/json/videos2/<缓存>/str/<排序>/60/<段>.<对象>.<页>.all...json`、`/api/videos.php?params=.../search..<页>.all...&s=<关键词>`、`/api/json/video/<缓存>/<百万段>/<千段>/<id>.json`，不解析网页。
- 分类列表取自 `/api/json/categories/<缓存>/str.all.en.json`，缓存 12 小时；取不到时只留三个排序项。
- 分页按接口返回的 `pages` 判定；同一分类的下一页与上一页内容相同（站点缓存没刷新）时换一个缓存周期重取一次，仍相同就停止翻页。
- 播放地址：`/api/videofile.php?video_id=<id>` 返回的 `video_url` 是 base64 的变体——用西里尔（还有少量希腊）同形字母替代 A / B / E / K / M / H / O / P / C / T / Y / X，逗号代替加号，末尾 `~` 收尾；解码后得到 `/get_file/...` 路径，路径里的 `>` 视为 `?`。
- 该地址会 302 到 `*.ahcdn.com` 的签名直链（`ti` 有时效），播放器和下载都跟随跳转；每次播放重新解析，不缓存直链。站点只提供一档 mp4，没有多清晰度。

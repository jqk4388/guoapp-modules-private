# Netfuck

小果影视（guoapp）站源模块，接口第 1 版。

- 内容：日本 JAV 男同影片，含片商、系列分类
- 功能：分类浏览、分页（自动加载更多）、搜索、详情、播放
- 限制级：是

## 安装

在应用「模块」页从 zip 安装，或把本目录放到数据目录的 `modules/netfuck/`。

## 说明

- 目录和搜索走站点的 WordPress 列表页（`/` 首页、`/category/<分类>/`、`/?s=<关键词>`），分页形如 `/category/movies/page/2/`，分类 id 允许带子路径（例如 `coat/ckオリジナル`）。首页不吐翻页链接时按满页推定还有下一页，并用 `?paged=N` 兜底；同一页内容重复就停。
- 站点文章量很大（十余万），只用列表页和搜索，不拉全量目录。
- 详情页的播放器是第三方嵌入页（`gayporntube.net/embed/<id>`），也可能是页面里的 `<video>` 直链。模块先取播放器地址，再在播放器页里解出 `get_file` 的 mp4（也认 `file`、`sources`、`.m3u8`）；播放器换到未声明的域名时，报错会直接写出那个域名。
- 该嵌入页对 `Referer` 有白名单：只能是 javboys、gaypornhot、netfuck 这几个站域，所以请求时固定带本站 `Referer`；播放直链再用嵌入站自己的 `Referer` 请求。
- 站点对 TLS 指纹敏感（普通 HTTP 客户端握手阶段就被重置）。清单开 `browserFingerprint` 后，`hosts` 里声明的域名都走应用的 Chrome 指纹通道；共享的嵌入域名放 `hosts` 不放 `aliases`，标识不冲突，三个站源可以同时安装（需要 2.0.3+115 及以后的应用）。
- 直链带 `v-acctoken` 时效签名，每次播放都重新解析，不缓存播放地址。
- 片名里的注音（`<ruby>` 的 `rt`）会被去掉，保留日文正文。

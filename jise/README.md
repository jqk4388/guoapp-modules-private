# 基色短剧

小果影视（guoapp）站源模块，接口第 1 版。

- 内容：真人剧、AI 剧、标签分类、排行榜
- 功能：分类浏览、分页、搜索、详情、播放、**账号登录**、**自动签到**、**金币解锁分集**
- 限制级：是

## 安装

在应用「模块」页从 zip 安装，或把本目录放到数据目录的 `modules/jise/`。

## 账号

- 在「我的 › 模块 › 基色短剧」卡片上点「登录」，填站点账号和密码，登录后用这个账号签到、解锁和播放。
- 没有账号或不想登录时不用管：第一次用到站源会用 `POST /api/member/auto/register` 自动注册一个游客账号，站点注册页可以改邮箱和密码。
- 登录信息存在模块状态 `jise-session`（账号、密码、accessToken、refreshToken）里；令牌快过期时用 `/api/refreshToken` 续期，续期失败不会换账号，只有完全没有账号时才会自动注册。
- 点「退出登录」会调用 `/api/member/logout` 并清掉本地登录状态，下次用到站源重新自动注册游客。

## 签到与金币

- 播放时会检查当天是否已签到：没签到就 `GET` 一次签到状态，未签到则 `POST /api/member/daily-check-in`，同一天只做一次，失败 10 分钟内不重试。取分类、翻页和详情不再顺带签到，避免账号接口卡住时连浏览一起失败。
- 播放未解锁的分集时先算好从当前第一个未解锁集到目标集一共要多少金币，余额够才 `POST /api/member/dramas/{id}/unlock` 逐集解锁，余额不够直接提示「需解锁（X 金币）／余额 Y」，不会花掉一半金币后失败。

## 说明

- 目录来自 `/api/dramas`，一次取全量后在本地分页、排序，结果缓存 3 分钟；返回 `items`、`list`、`records`、`rows` 或直接数组都认。
- 搜索用接口的 `search` 参数，再按剧名和标签二次过滤。
- 分类标签来自 `/api/dramas/tags`，取不到时只保留内置的几个分类，不会让整个分类列表失败。
- 详情里没有可用分集时照样返回剧集信息，由应用提示「暂时没有可播放的集数」，不把整页判成加载失败。
- 登录接口有频率限制，连续输错会返回「请求过于频繁，请稍后重试」，等一会再试。
- 「成人剧」分区在未登录时站点返回空列表，本模块不提供该分区。
